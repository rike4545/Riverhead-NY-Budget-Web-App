A number should come with a path back to the record.

This project combines official public records with calculations that make those records easier to understand. The label matters: a Town-reported figure, a calculation made from Town records, and a forward-looking scenario are not the same thing.

How to read the labels

Official source

Reported directly in a cited Town or other official public record.

Calculated from source data

Computed by the site from cited records. The calculation is ours; the underlying records are not.

Projection / scenario

Forward-looking or hypothetical. Read the assumptions before treating it as a forecast.

Three rules for using the site

1
Prefer the cited record.

When a page links to a source document, use that document to verify the underlying figure.

2
Separate reporting from calculation.

A computed percentage, total, comparison, or estimate may be mathematically correct without being a number the Town itself reported.

3
Read the scope.

Town taxes are not the same as the full property-tax bill; appropriations are not the same as actual spending; a scenario is not a prediction.
