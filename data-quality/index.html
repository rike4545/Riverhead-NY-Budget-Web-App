Checks enforced before deployment

Routes
Navigation links must resolve to an exported page.
Record floors
Core datasets cannot silently collapse to zero or an implausibly small record count.
Search shards
Manifest counts and byte sizes must match the generated shard files, and the legacy monolith must stay removed.
Payload guardrail
Unexpected search-index growth fails verification instead of silently shipping a much larger download.
Dataset freshness
Every tracked dataset must declare a cadence, freshness policy, status, and as-of value; pipeline-owned data must be current after regeneration.
ETL imports
Python dependencies and ETL modules are smoke-tested before the web build starts.
Static build
TypeScript and the Next.js static export must compile successfully before merge.

How to interpret the labels

Official sourceCopied or parsed from a cited government record. Parsing can still introduce transcription errors, so consequential use should be checked against the source.
Calculated from source dataComputed by this site from cited records. The calculation should be reproducible from the linked source data.
Projection / scenarioForward-looking model or scenario. It is not an adopted Town budget or official forecast.
Independent. Source-first. Built for residents.

Riverhead Budget Live is not affiliated with the Town of Riverhead. Important figures should be checked against the linked official record. Google Analytics is used to understand aggregate site usage; no account is required to use the site.
