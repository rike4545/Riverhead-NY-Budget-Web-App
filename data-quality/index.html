Checks enforced before deployment

Routes
Navigation links must resolve to an exported page.
Record floors
Core datasets cannot silently collapse to zero or an implausibly small record count.
Search shards
Manifest counts and byte sizes must match the generated shard files, and the legacy monolith must stay removed.
Payload guardrail
Unexpected search-index growth fails verification instead of silently shipping a much larger download.
Dataset freshness
Every tracked dataset must declare a cadence, freshness policy, status, and as-of value; pipeline-owned data must be current after regeneration.
Data contracts
Canonical payroll, meeting, budget-line, AFR, tax-rate, search-shard, freshness and native-manifest data must keep their required fields, keys, counts and arithmetic.
Claim-level evidence
Nine analytical pages must expose stable claim IDs with a source, as-of date and official, calculated or projected classification in the rendered page.
Browser accessibility
Playwright checks core resident routes at desktop and 320px widths; axe checks WCAG 2.0, 2.1 and 2.2 A/AA. Critical violations and horizontal overflow fail the quality gate; other findings are reported for review.
Visual QA snapshots
Desktop and narrow-phone screenshots of the home page and key analytical pages are saved as CI artifacts for review when the interface changes.
Research packet integrity
Three curated ZIP packets are built from canonical data; each archive is tested and every included file is checked against its SHA-256 manifest before publication.
ETL imports
Python dependencies and ETL modules are smoke-tested before the web build starts.
Static build
TypeScript and the Next.js static export must compile successfully before merge.

How to interpret the labels

Official source. Reported directly in a Town or other cited official record.Copied or parsed from a cited government record. Parsing can still introduce transcription errors, so consequential use should be checked against the source.
Calculated from source data. Computed by the site from cited source records; it is not a separate Town-reported figure.Computed by this site from cited records. The calculation should be reproducible from the linked source data.
Projection / scenario. A forward-looking estimate or scenario based on stated assumptions.Forward-looking model or scenario. It is not an adopted Town budget or official forecast.
Independent public-records guide for Riverhead residents.

Riverhead Budget Live is an independent project. It is not run, approved, or endorsed by the Town of Riverhead. The site organizes public information and provides analysis; it is not a substitute for the Town’s official records. Check the linked source documents before relying on an important figure. Basic, aggregated site-usage statistics are collected through Google Analytics. You do not need an account to use this site. There are no ads.
